# UEG 行政管理中心 · 联合政府地球联合管理中心

以 [https://www.uegov.world/](https://www.uegov.world/)（UEG 地球联合政府《流浪地球》主题官网）为设计蓝本，构建的 **《流浪地球》联合政府管理后台** 演示系统。

深色科幻风 UI（深海军蓝 + 青色遥测强调 + 网格/数据面板），中文界面，面向中国政府官员使用场景。

## 技术栈

- Vite + React 18
- 手写 CSS 深色科幻主题（复刻 uegov.world 配色与风格）
- Hash 路由（便于任意静态托管部署，无 404 回退问题）
- localStorage 模拟数据持久化（页面间增删改查真实交互）

## 本地运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

## 部署

本项目已配置 `vercel.json`，可直接导入 GitHub 仓库到 Vercel 一键部署（免费 Hobby 计划即可），或：

```bash
npm i -g vercel
vercel            # 交互式登录并部署
vercel --prod     # 部署到生产
```

本项目可正常部署到 Vercel 免费计划，无需付费。

## 功能模块

- **全局总览**：人口 / 发动机 / 聚变核心等关键运行指标 + 全局通联广播
- **全球人口数据**：地下城节点人口分布（可编辑、保存）
- **行星发动机**：发动机状态看板（可新增 / 编辑出力 / 改状态）
- **地下城与空间站**：地下城运行状态登记
- **政务办理**：发起申请 + 待办受理队列 + 服务目录
- **官员与人事**：关键官员名录（搜索 / 保密级别）
- **公文与通告**：发布通告 + 公文流转队列
- **法律与宪章**：核心法律文库
- **决策分析**：KPI + 迁移趋势 + MOSS 量子辅助建议
- **系统终端**：MOSS 命令行交互（输入 `help` 查看命令）
- **系统设置**：安全策略 + 数据诊断 / 重置
